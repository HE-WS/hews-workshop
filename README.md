# HE Workshop job control

Hydraulic Engineering SARL — job sequence, plate stock, leftovers, accessories and history for the
plasma, laser, bending and rolling machines.

- Website: this repository, published with **GitHub Pages** (Settings → Pages → main / root).
- Data, log-ins and photos: **Supabase** (see `SETUP-GUIDE.txt` in the setup package).
- `config.js` holds the Supabase Project URL and the public anon key. Never put the service-role key here.
